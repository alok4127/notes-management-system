# Notes Management System

A full-stack Notes Management System built using React.js, Express.js, and MongoDB Atlas.

## Features

* Create Notes
* View Notes
* Edit Notes
* Delete Notes
* MongoDB Data Persistence

## Tech Stack

### Frontend

* React.js
* Vite

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas

## Installation

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
